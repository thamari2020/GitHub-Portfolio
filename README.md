### 👩‍💻 About Me

I'm a committed Quality Assurance Engineer who cares deeply about delivering reliable, high-quality software. I started my journey with manual testing, where I developed a sharp eye for detail and a mindset for quality. Over time, I expanded into automation, using Selenium with Java for UI testing and Playwright for API testing — blending precision with speed.

I’ve worked closely on real-world healthcare applications, testing both web and mobile platforms, and ensuring that every release meets user expectations. I enjoy uncovering hidden issues, designing thoughtful test scenarios, and constantly learning new tools that make testing smarter and faster.

To me, QA is not just about finding bugs — it’s about building trust in software.
